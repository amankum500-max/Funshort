# 🎬 Funshort

Funshort ek web-based short video platform hai jise mobile aur desktop dono par chalane ke liye design kiya gaya hai.

## 🚀 Features

* 📱 **Short Video Feed**: Smooth aur interactive video scrolling interface.
* ⚡ **Fast & Responsive**: Mobile-friendly aur lightweight design.
* 🛠️ **Simple Backend**: Python/Flask aur HTML/JS ke sath easy integration.

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3, JavaScript
* **Backend**: Python (Flask)
* **Hosting / Deployment**: GitHub / Render
